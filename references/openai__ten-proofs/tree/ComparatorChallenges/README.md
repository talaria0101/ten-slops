# [Comparator](https://github.com/leanprover/comparator) challenges

Install `landrun`, `lean4export`, and `nanoda_bin`, and make them available on
`PATH`. Then, from the repository root:

```sh
lake exe cache get
lake exe comparator ComparatorChallenges/A_SpherePacking.json
```

Replace `A_SpherePacking.json` with any other challenge configuration in this
directory.
